# Miner-a-de-datos-bioinform-ticos
El objetivo de esta actividad se centra en la aplicación de las herramientas de minería de datos bioinformáticos aprendidas hasta ahora. Entre estas habilidades se encuentran: el manejo de API para realizar consultas a bases de datos biológicas y químicas, así como el uso de bibliotecas especializadas en la manipulación de estos datos.
